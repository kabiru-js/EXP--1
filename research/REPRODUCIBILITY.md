# Reproducibility Guide

## Environment

- **Python:** 3.11
- **OS:** Windows (PowerShell 5.1)
- **PyTorch:** 2.8.0+cpu (CPU-only build — no CUDA)
- **Transformers:** 4.56.2
- **Hardware:** CPU only (4 cores), no NVIDIA GPU/driver

## Installation

```bash
pip install -e ".[dev]"
```

This installs all dependencies listed in `pyproject.toml`.

## Running Experiments

### EXP-001

```bash
# Full run (1000 samples, ~23 minutes on CPU)
python scripts/run_exp001.py

# Quick test (100 samples)
python scripts/run_exp001.py --samples 100

# Force re-run (clears existing data)
python scripts/run_exp001.py --force

# Resume (skip existing samples)
python scripts/run_exp001.py --resume

# Analyze only (no generation)
python scripts/run_exp001.py --analyze-only

# Override config
python scripts/run_exp001.py --model gpt2 --samples 500
```

### Cross-Validation Check

```bash
python scripts/cv_check_exp001.py
```

### EXP-002

```bash
# Chain-continuation probes (distilgpt2)
python scripts/scratch/probe_chains.py

# Qwen probes (NOT RUNNABLE on CPU-only hardware)
python scripts/scratch/probe_qwen_chains.py
```

## Running Tests

```bash
# Smoke test (recommended — pytest hangs in this environment)
python tests/smoke_test.py

# Individual test modules
python -c "from tests.test_analysis import *"
python -c "from tests.test_config import *"
```

**Note:** `pytest tests/` hangs in PowerShell. Use `python tests/smoke_test.py` instead.

## Configuration

Experiments are configured via YAML files in `configs/`. The main config is `configs/EXP-001.yaml`.

To create a new experiment config:
1. Copy `configs/EXP-001.yaml` to `configs/EXP-002.yaml`.
2. Modify the parameters.
3. Run: `python scripts/run_exp001.py --config configs/EXP-002.yaml`.

## Reproducing Figures

Figures are generated automatically during the experiment run. To regenerate:

```bash
# Analyze existing data (regenerates figures)
python -c "from src.experiments.runner import ExperimentRunner; from src.config import ExperimentConfig; r = ExperimentRunner(ExperimentConfig.from_yaml('configs/EXP-001.yaml')); r.analyze()"
```

Or use the CLI:
```bash
research analyze --config configs/EXP-001.yaml
```

## Data Storage

Trajectory data is stored in `experiments/EXP-001/`:
- `trajectories/` — one Parquet file per trajectory
- `trajectories.duckdb` — DuckDB metadata table
- `results.json` — aggregated results
- `cv_results.json` — cross-validation results
- `figures/` — PNG and SVG figures

## Exact Commands Used

The following commands were used to produce the current results:

1. EXP-001 full run: `python scripts/run_exp001.py`
2. EXP-001 CV: `python scripts/cv_check_exp001.py`
3. EXP-002 probes: `python scripts/scratch/probe_chains.py`
4. EXP-002 report: Generated by `ExperimentRunner.analyze()`

## Known Issues

- **pytest hangs** in PowerShell. Use `python tests/smoke_test.py`.
- **Qwen2.5-0.5B-Instruct not cached.** Download was infeasible.
- **No GPU.** All experiments run on CPU.
- **Generation is slow** (~1.4s/sample for distilgpt2). Large sample sizes are time-prohibitive.
